# Session 1 Exit Ticket

## Form introduction

Respond briefly to each question. The purpose is to consolidate today’s learning and help shape upcoming course examples and support.

## Questions

1. What is one distinction about research that became clearer to you today?
2. What assumption about research did today’s class make you reconsider—or become more aware of?
3. Based on today’s discussion, what is one thing you will do differently when using AI for academic work?
4. If you could investigate one educational problem this semester, what would you currently choose?

## Recommended settings

- Use paragraph-style responses.
- Do not grade for correctness.
- If the activity contributes to completion credit, collect only the minimum course identifier needed through the approved platform.
- Export or review responses before Session 2 to identify common research interests and areas requiring clarification.
